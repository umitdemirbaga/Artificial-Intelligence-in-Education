## Chapter-specific notes

**Chapter 2 · UCI Student Performance.** The notebook uses the *Mathematics* course file `student-mat.csv` with semicolon-separated values. `G3` provides the class label. Earlier grades `G1` and `G2` are predictors, so reported performance should be interpreted as relatively short-horizon prediction. The source provides two subjects; do not substitute `student-por.csv` without documenting the change.

**Chapter 3 · UCI Higher Education Students Performance Evaluation.** The model uses the dataset's coded educational and demographic attributes, with academic risk defined for this book as `GRADE <= 2`. Risk labels and action thresholds are operational choices, not immutable student characteristics.

**Chapter 4 · Kaggle Student Performance and Learning Behavior.** Use the file whose columns match those expected by the notebook. The final six-cluster analysis uses nine behavioural/contextual features; academic outcome variables are analysed only after clustering. Confirm source terms on Kaggle before redistribution.

**Chapter 5 · Mendeley Data v4.** Cite the dataset and **version 4** (`10.17632/vzfyk22fhn.4`). Learned score-based Bayesian network edges encode dependencies under modelling assumptions, not identified causal effects.

**Chapter 6 · Kaggle Mental Health Sentiment.** The dataset should not be mischaracterised as a sample of students. Text labels and model predictions cannot substitute for clinical assessment. Do not use the content to identify or profile individuals.

**Chapter 7 · Google Research Education Dialogue.** The dataset consists of **simulated** teacher–student conversations generated by Gemini Ultra. It is not a dataset of directly observed classroom sessions. Interpret linguistic features as corpus descriptors, not evidence of learning outcomes or psychological change.

**Chapter 8 · Roboflow SCB-Dataset3 v3.** The given Roboflow version has different class labels from the book's historical *Doing Homework*, *Listening*, and *Looking Around* categories. Treat model training on the linked export as a **new companion experiment**, not as a reproduction of the chapter's original training or evaluation.

**Chapter 9 · Archived evaluation.** The figure notebook embeds an anonymised numerical tabulation sufficient for the documented summary statistics. The released F1/F2.1 implementation uses synthetic demonstration cases. Original problem statements, historical model predictions, gold answers and individual expert-annotation source files are not distributed. The sample should not be described as completely sampled from MathDial without independent source evidence.

## Citation practice

When publishing a study based on these materials, identify the precise dataset source, original authors, version/DOI where available, and any deviations from the book’s data preparation or model configurations. Avoid claiming independent reproduction of historical results when restricted inputs or inference environments are unavailable.
