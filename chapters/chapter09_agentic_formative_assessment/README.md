[`Chapter09_Agentic_Formative_Assessment_Results_and_Figures.ipynb`](Chapter09_Agentic_Formative_Assessment_Results_and_Figures.ipynb) — **13 documented code cells**. ## Source material

- **Source:** Chapter 9 historical evaluation records
- **Expected input:** `Numeric anonymised tabulation embedded in the results notebook`
- **Data permissions:** Original held-out questions, model outputs, and reviewer records are not distributed.

## How to run

1. Follow the installation instructions in the [repository README](../../README.md).
2. The results notebook uses the embedded anonymised numeric tabulation; no additional dataset is required for its figures. The original held-out assessment cannot be independently rerun from these data alone.
3. Start Jupyter from **this chapter directory** (or use JupyterLab’s file browser to open this directory) and run cells in order.
4. Inspect figures and generated results in the output locations defined at the top of the notebook (usually `figures/`).

**Optional components:** For the included F1/F2.1 source distribution, see `implementation/README.md`; run its unit tests from the `implementation/` directory.

## Interpretation and reproducibility

The results notebook includes anonymised numerical aggregates and problem-level tabulations from the earlier analysis; original 76 problem texts and independent rating materials are not public. The system implementation is available separately below.

Run-time metrics, figure values, and model outputs may differ by dataset version, package version, random seed, model checkpoint, or computing environment. Do not substitute companion-notebook outputs for archived book results without an explicit match of the experimental conditions.
